# Linux System Monitoring Script

A beginner-friendly infra project for monitoring basic Linux system resources.

## Project Overview
This project checks basic system status such as CPU load, memory usage, disk usage, and network connectivity using Linux commands.

## Features
- Check CPU load
- Check memory usage
- Check disk usage
- Check network connection with ping
- Save monitoring results to a log file

## Technologies
- Linux
- Bash Script
- Basic Networking
- System Monitoring

## How to Run

```bash
chmod +x monitor.sh
./monitor.sh
```

## Sample Commands Used
- `uptime`
- `free -h`
- `df -h`
- `ping`

## What I Learned
Through this project, I practiced basic Linux commands and understood how to check system status from an infrastructure operation perspective.
